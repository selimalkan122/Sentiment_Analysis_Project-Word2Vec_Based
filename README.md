# Yelp Review Sentiment Analysis

## Project Overview

This project was developed to practically apply and deepen knowledge of various Natural Language Processing (NLP) techniques learned in the Text and Web Mining course. The primary objective is to analyze user reviews from Yelp and classify their underlying sentiments into three distinct categories: **Negative**, **Neutral**, and **Positive**.

A simple **web interface** and **REST API** are included so you can run predictions in the browser or via HTTP.

## Key Features and Methodology

* **Custom-Trained Word2Vec:** A custom Word2Vec model is trained on the dataset to capture the specific jargon and nuances of Yelp reviews.
* **Context-Aware Text Processing:** Reviews are left raw for VADER scoring; a cleaning pipeline (POS-tag-aware lemmatization) is used for Word2Vec.
* **Hybrid Feature Engineering:** TF-IDF weighted Word2Vec embeddings are concatenated with VADER sentiment scores.
* **Class Imbalance:** SMOTE is used inside an `imblearn` Pipeline to avoid data leakage.
* **Benchmarking:** Four feature configurations × four classifiers (Logistic Regression, SGD, Random Forest, XGBoost) are evaluated; the best model is then tuned with RandomizedSearchCV.

## Installation

1. **Clone the repository** (or download the project).

2. **Create a virtual environment** (recommended):

   ```bash
   python -m venv .venv
   .venv\Scripts\activate   # Windows
   # source .venv/bin/activate   # Linux/macOS
   ```

3. **Install dependencies:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Download NLTK data** (first time only):

   ```python
   import nltk
   nltk.download("stopwords")
   nltk.download("punkt")
   nltk.download("averaged_perceptron_tagger")
   nltk.download("wordnet")
   nltk.download("vader_lexicon")
   ```

## How to Run

### 1. Train the model and save artifacts

From the project root (takes several minutes):

```bash
python -m src.train_and_save
```

This writes `artifacts/w2v.model`, `artifacts/tfidf.pkl`, `artifacts/best_pipeline.pkl`, and `artifacts/metadata.json`.

### 2. Start the web server

```bash
python -m uvicorn src.app:app --reload
```

Open **http://127.0.0.1:8000** in your browser. Enter a sentence and click the button to see the predicted sentiment and confidence score.

### 3. API usage

```bash
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d "{\"text\": \"The food was amazing!\"}"
```

## Limitations and Future Work

The **Neutral** class is often confused with Positive and Negative, due to limitations of Word2Vec and rule-based VADER with context and sarcasm. Future work may use **Transformer-based models (e.g. BERT, RoBERTa)** for better contextual understanding.
